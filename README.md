# squared-netizen

I build **squared**, a C++23 framework for Linux and Android, and the tools
around it, on an Android phone, offline-first, with no Java and no Gradle.

**Projects, plans and the sprint tracker: https://squared-netizen.github.io/squared-netizen/**

| Project | What it is |
|---|---|
| [squared](https://github.com/squared-netizen/squared) | C++23 framework (named modules) for Linux and Android |
| [squared-pg](https://github.com/squared-netizen/squared-pg) | Offline-first project generator: C++20 engine, Lua 5.4 workflows |
| [sqcart](https://github.com/squared-netizen/sqcart) | The `.sq` cartridge format and its reference implementation |
| [sqterm](https://github.com/squared-netizen/sqterm) | A terminal for Android on squared, with its own clang 23 toolchain |
| [squared-examples](https://github.com/squared-netizen/squared-examples) | Example apps generated by squared-pg |

<sub>The pages are plain HTML from `tools/build.py` (facts in
`tools/projects.py`); the tracker reads pull requests and Actions runs live
from GitHub.</sub>
