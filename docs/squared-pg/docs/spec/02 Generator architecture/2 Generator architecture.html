2. Generator architecture

[!info] Navigation Index: [[Specification Index]] · Prev item: [[1 Repository conventions]]

Purpose

Defines the runtime architecture of squared-pg: a native C++20 engine providing capabilities, a Lua 5.4 control layer providing orchestration, and the generation model that turns configuration into a user-owned workspace.

The governing idea: the engine provides capability, Lua provides orchestration. Every section below is a consequence of that split.
