1.4 Lua

[!info] Navigation Index: [[Specification Index]] · Parent: [[1 Repository conventions]] Prev: [[1.3 Engine]] · Next: [[1.5 Resources]]

Purpose

Defines the lua/ component's ownership rules.

Outline

  • ☑ component scope
  • ☑ module ownership rule
  • ☑ boundary-crossing prohibition
  • ☑ pointer to local conventions

Content

lua/ contains the Lua implementation of generator functionality.

Lua modules MUST have clearly defined ownership and responsibilities. Modules MUST NOT silently cross architectural boundaries by reaching into unrelated subsystems through global state.

Lua-specific development conventions are defined by lua/AGENTS.md.
