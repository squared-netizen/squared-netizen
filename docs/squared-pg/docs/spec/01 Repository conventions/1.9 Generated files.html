1.9 Generated files

[!info] Navigation Index: [[Specification Index]] · Parent: [[1 Repository conventions]] Prev: [[1.8 Documentation]] · Next: [[1.10 Naming]]

Purpose

Keeps reproducible artifacts out of the source tree.

Outline

  • ☑ artifacts are not source
  • ☑ exclusion mechanism

Content

Generated build artifacts MUST NOT be treated as repository source.

Build directories, compiler outputs, generated documentation, temporary archives, and other reproducible artifacts SHOULD remain outside the canonical source tree or be excluded through repository ignore rules.
