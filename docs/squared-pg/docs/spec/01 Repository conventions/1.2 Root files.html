1.2 Root files

[!info] Navigation Index: [[Specification Index]] · Parent: [[1 Repository conventions]] Prev: [[1.1 Repository identity]] · Next: [[1.3 Engine]]

Purpose

Defines the required contents of the repository root.

Outline

  • ☑ required root files
  • ☑ policy on additional root files

Content

The repository root contains:

  • CMakeLists.txt — top-level CMake configuration
  • README.md — concise project overview and user-facing entry point
  • AGENTS.md — repository development and automation conventions
  • .clang-format
  • .clang-tidy

A Lua language-server configuration (.luarc.json) is a recommended addition for the Lua control layer tooling; it is not yet present on disk and is not a hard requirement until the Lua tooling runs against the repository.

Additional root-level files and directories MAY exist when they serve a repository-wide purpose. sqcart/ is such a case: it is a nested development project, not an engine directory (see [[1.1 Repository identity]]).
