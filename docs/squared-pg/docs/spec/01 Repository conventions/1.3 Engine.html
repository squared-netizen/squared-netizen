1.3 Engine

[!info] Navigation Index: [[Specification Index]] · Parent: [[1 Repository conventions]] Prev: [[1.2 Root files]] · Next: [[1.4 Lua]]

Purpose

Defines the engine/ component's repository layout and its public/private boundary.

Outline

  • ☑ component scope
  • ☑ required component files
  • ☑ header layout
  • ☑ public/private boundary rule

Content

engine/ contains the native C++ implementation of functionality belonging to the generator/runtime support layer rather than to generated application code.

It MUST be treated as a distinct component with its own:

  • CMakeLists.txt
  • AGENTS.md
  • README.md

Public C++ headers belong under engine/include/. Implementation files belong under engine/src/.

The public/private boundary MUST be explicit. Implementation headers MUST NOT be exposed as public API merely for convenience.
