1.6 Third-party dependencies

[!info] Navigation Index: [[Specification Index]] · Parent: [[1 Repository conventions]] Prev: [[1.5 Resources]] · Next: [[1.7 Tools]]

Purpose

Defines vendoring rules for offline capability.

Outline

  • ☑ purpose of vendoring
  • ☑ current dependency set
  • ☑ cache and integrity location
  • ☑ modification prohibition

Content

third-party/ is the repository location for vendored dependencies required to build or run the generator offline.

[!warning] Status The third-party/ directory exists on disk but currently contains only a placeholder (.gitkeep). None of the dependencies below are vendored yet. The list is the intended set and governs what the directory is for, not what it currently holds.

Intended dependency set:

DependencyVersion
Lua5.4.8
LuaFileSystem1.8.0
Penlight1.14.0
LDoc1.5.0
miniz3.1.2
yyjson0.12.0

Downloaded source archives and integrity information belong under third-party/cache/.

Vendored source trees MUST remain versioned and identifiable.

Third-party code MUST NOT be modified unless the modification is explicitly required by squared-pg and documented.
