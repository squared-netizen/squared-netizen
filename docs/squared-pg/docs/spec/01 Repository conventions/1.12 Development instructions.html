1.12 Development instructions

[!info] Navigation Index: [[Specification Index]] · Parent: [[1 Repository conventions]] Prev: [[1.11 Dependency direction]] · Next: [[1.13 Repository invariant]]

Purpose

Defines how AGENTS.md files govern local development.

Outline

  • ☑ role of AGENTS.md
  • ☑ nesting and override behaviour
  • ☑ obligation to inspect

Content

AGENTS.md files define local development constraints.

A nested AGENTS.md overrides or supplements the applicable parent instructions for its directory.

Agents MUST inspect applicable AGENTS.md files before modifying code.
