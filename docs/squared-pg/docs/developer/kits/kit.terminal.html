Design patterns

PatternWhereWhy / deviation
Facadethe regex functions over <regex>Four-argument std::regex calls and exceptions become one-line, non-throwing calls. Deviation: it is a set of free functions rather than a class, because there is no state to hold. pattern() is the escape hatch to the real type.
Value objectFileHandleA cheap, copyable wrapper around std::filesystem::path with no identity. Modelled on libGDX, so it keeps libGDX's names (readString, child) rather than the standard library's.

Not a pattern but a convention: std::optional is the error channel everywhere. A terminal program's reaction to "no such file" is to print and carry on, so exceptions would only be caught at every call site.

Data structures and complexity

  • Regex results are std::vector<std::string>; find reserves match.size().
  • list() sorts with std::sort: O(n log n), because directory order is not stable.
  • readLines() and readString() are O(file size). The whole file is held in memory; this kit is not for large files.
  • Each regex call compiles its pattern again. std::regex construction is slow, so a loop over many lines should call pattern() once and use <regex> directly.

Standard library versus custom

Nothing third-party. Custom code where the standard library has no equivalent or a worse fit:

  • trim: there is no std::trim; six lines.
  • parse<T>: wraps std::from_chars instead of std::stoi, which throws and accepts trailing garbage. Integer T works everywhere; floating-point T depends on the standard library's from_chars support, which older libc++ releases lack. Verify on-device before documenting parse<double> as supported.
  • readLines: a character loop instead of std::getline over a stream, so CRLF handling and the "no final empty line" rule live in one place.
  • FileHandle has one constructor, not three, because overloads for string types make FileHandle{some_string} ambiguous.

Invariants

  • Header-only, every function inline or a template, include-guarded.
  • No function throws. Anything that can fail returns a value that says so.
  • Compiles warning-free under -std=c++20 -Wall -Wextra -Wpedantic.
  • No terminal control (design note in the header).

Verification

Each release: build a template.terminal.cpp workspace with the kit, run it, and compile a smoke test calling every function under the flags above.
