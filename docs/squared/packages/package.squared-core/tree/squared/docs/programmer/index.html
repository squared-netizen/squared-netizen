squared &mdash; programmer documentation

For people building something with squared. Nothing here describes an internal: for that, see ../developer/README.md.

Modules

  • app &mdash; the platform-neutral lifecycle, event and text-input boundary
  • assets &mdash; typed asset cache with dependency tracking
  • console &mdash; the Console, compiled in with CONSOLE=app: commands and the built-ins, input, history, scrollback, crash reports, and drawing it
  • data &mdash; strict RFC 8259 JSON parsing and writing
  • dev &mdash; development aids: a loopback log sink and its listener, crash reporter and frame-allocation counter (not in release builds)
  • files &mdash; virtual filesystem and libGDX-style file handles; files compiled into the program (EmbeddedFileSystem, tools/embed_files.sh)
  • font &mdash; font faces read and rendered at run time (FreeType): cell metrics, glyphs as 8-bit coverage, bold and italic made; fallback faces; a glyph atlas for one texture
  • gles &mdash; the GL object layer: buffers, shaders, programs, textures
  • graphics &mdash; the rendering context and colour, then textures, atlases, sprites, the sprite batch, the 2D camera and bitmap fonts
  • gui &mdash; the libGDX-flavoured widget set and skinning, on the Actor/Group/Widget tree and its input routing (the host is internal since 7.7)
    • layouts &mdash; screens and panes as data: the node table, writing one from C++, layout files, names.json, the sqgen build step, taps, and building widgets from it
  • stage &mdash; the App and the Stage: squared_main, the model at the Telegraph's far end, the stack of screens, C++ screens and custom nodes, panes, taps, the window, and what is reported
  • term &mdash; a terminal emulator's core: bytes from a program in, a screen of 12-byte cells out (ECMA-48 over UTF-8), and a program in a pseudo-terminal (Pty); sqterm's, Sprint 12
  • messaging &mdash; the Telegraph: names, addresses, keys, the 32-byte telegram and its text form, the rings, the cache, lists, both ends, and the model's thread
  • math &mdash; small value types used across the framework
  • time &mdash; the time between ticks (Timepiece), the clocks, and a model's timers (DeadlineQueue)

import squared; is everything an app is written against: the standard library (std), app, gui, messaging and stage. Private partitions under src/detail/ are not counted: they are the framework's own.

Reading the tables

Each module page lists every public type, the file that defines it, and what it is for. One type, one file: squared/gui/button.cppm defines sq::gui::Button and nothing else.

A type at the module root is one you will reach for. A type under src/ is a supporting type &mdash; a style, an error code, an options struct &mdash; that comes with it. One import gives both: import sq.gui;. See include-layout.md.
