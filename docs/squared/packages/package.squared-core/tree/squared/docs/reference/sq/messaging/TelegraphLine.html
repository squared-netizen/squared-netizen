class TelegraphLine

Defined at messaging/telegraph.cppm:586

brief The Telegraph's storage and its two ends: the line between the UI station and the model's. The App owns one, made once at start (about 90 KB at the default knobs, every array inside it, and two eventfds); the model is handed model(), the Stage ui(), and neither can reach the other's. A ModelRunner runs the model's end.
