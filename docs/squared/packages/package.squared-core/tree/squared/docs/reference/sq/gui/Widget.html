brief Base class for every GUI node. Widgets may own other widgets.

Widget inherits the composite ownership model: children owned via Group. Widgets carry layout, painting, and input behavior.

pinch

public bool pinch(const PinchEvent & event)

brief Take a two-finger pinch that starts over this widget, instead of the UI's zoom: a terminal scales its font, a map its view.

The Stage offers begin to the widget under the fingers' middle, then to its parents, until one returns true; that one gets the pinch's changes and its end. When none takes it, the whole UI zooms (Stage::zoom). Both fingers' pointer events stop while it lasts, and the first finger's press is cancelled (PointerAction::cancel).

event The pinch, its middle in widget-local logical units.

return At begin: true to take it (false, the default, to leave it). Ignored after.
