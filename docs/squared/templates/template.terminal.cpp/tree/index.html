Build and run

make          # build
make run      # build and run
./run.sh      # the same, in one step

No CMake, no package manager, no network. A compiler and make are the whole dependency list — which is the point of this template: it is meant to work on a phone.

Layout

sq_app/        your code — headers in include/, sources in src/
sq_kit/        kit-provided headers (generator-owned)
mk/            generated build fragments (generator-owned)
Makefile       yours; includes the fragments above
.squared/      how this workspace was generated (generator-owned)

Every generated path is recorded in .squared/metadata.json with the hash it had when it was written, so a later update can tell "unchanged since generation" from "the user edited this" without guessing.

You can delete .squared/ and keep a working project. You lose only the ability to update it in place.

Independence

This workspace does not depend on squared-pg. The generator is not on the build path, is not referenced by the Makefile, and does not need to be installed to build, run, test or distribute what it produced.

Where to start

sq_app/src/app.cpp. It has a small command loop demonstrating the terminal kit — console I/O, the regex helpers, and FileHandle. Delete what you do not want.
