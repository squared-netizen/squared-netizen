Squared

Squared is a rapidly evolving C++ framework and development ecosystem.

This repository holds squared's cartridges: the framework, package.squared-core, with the templates, kits and assets that sqpg (squared-pg) generates workspaces from.

Packages are squared-core and its add-on packages, squared-name (planned: see docs/design/). Nothing else is a package: an application, such as sqterm, can have a template, and a kit wraps a third-party library. sqterm's pkg installs programs into its own prefix; those are sqterm packages, a different thing that shares the word.

Design documents for what is planned are in docs/design/: squared-tui, character-cell programs.

Status

Squared is undergoing a ground-up rewrite and is currently unstable.

The project is in active development and APIs, architecture, tooling, and project structure may change substantially without notice. It should not currently be considered stable.

Development

The main branch contains the current implementation.

Previous experimental implementations are preserved in the repository's archive branches for historical reference only. They are not supported.
