sq.cart: the 3.0 reader and writer

The reader and writer for the Squared Cartridge Specification 3.0, as C++23 modules, in namespace sq::cart:

  • sq.cart: open, look up, read and verify, check signatures, validate.
  • sq.cart.write: commit, compact, sign. Its own module, so a program that only reads carries no compressor.

Nothing here shares code with the 2.0 library in ../src; 3.0 does not have to be compatible with it.

import std;
import sq.cart;

auto cart = sq::cart::Archive::open("world.sq");
if (!cart) { std::println(std::cerr, "{}", cart.error().message); return 1; }
if (auto e = cart->find("world/settlements/9001.json")) {
    auto bytes = cart->read(*e);                 // verified against its digest
    auto part = cart->read_range(*e, 0, 4096);   // a chunked entry: only those chunks
}
auto report = sq::cart::check("world.sq");       // §12, in full
import sq.cart.write;

auto w = sq::cart::Writer::open("world.sq");     // takes world.sq.lock (§10.2)
w->put("world/settlements/9001.json", bytes, {.title = "Northford", .flags = sq::cart::flag::r | sq::cart::flag::w});
w->put_range("world/map.bin", offset, patch);    // a chunked entry: only the chunks it touches
w->resize("world/map.bin", 8 << 20);             // cut, or grow with zeros
w->rename("world/map.bin", "maps/world.bin");    // the same runs, named again: nothing copied (§3.6)
w->put_file("video/intro.webm", "/sdcard/intro.webm");  // read at commit, 1 MiB at a time
w->put_range_file("world/map.bin", offset, "patch.bin", 0, n);  // a range, read from a file at commit
w->set_metadata("README.md", {.title = "Read me"});  // no content written again (§3.6)
w->remove("old.txt");
w->sign_with(sq::cart::SigningKey::from_seed(seed, "Jesse"));
auto commit = w->commit();                       // append, flush, spare slot, flush (§10.3)
sq::cart::compact("world.sq");                   // §10.4; or w->compact(), under the writer's own lock

auto id = w->train_dictionary(samples);          // many small, similar entries (§4.3)
w->put("world/settlements/9001.json", record, {.dictionary = *id});

Any number of ranges and resizes may be staged for one entry; they apply in the order given, and size() says what the entry's size will be. A second writer gets Code::busy; discard() drops what is staged. A commit that fails before its record is written cuts the file back to what it was.

The writer stores what is compressed already (by media type) or would not shrink 5%, chunks entries past 64 MiB, stores the manifest and mappable entries, writes a full index first and before the delta chain would pass its limit, and reads every commit back through the reader before it reports it done.

Building

make test                          # the library, sqcart3 and the tests, then run them
make CXX=/usr/lib/llvm-23/bin/clang++ test

Needs clang and libc++ with import std;: 23 is what sqterm's packages and CI use. The std module is built once from the libc++ the compiler names (clang++ -stdlib=libc++ -print-library-module-manifest-path). In sqterm, pkg install llvm brings clang, the sysroot and the runtimes (libc++ with its module sources).

sqcart3 is both on the command line: check, ls, cat, info and unpack to read; new, put, rm, mv, truncate, compact, keygen and pack to write (--sign KEYFILE signs a commit). make also builds sqcart3-read, the read commands linked against the reading archives alone: it holds no zstd compressor.

Opening, and what is checked when

Open reads the header, the superblocks, the commit records down to the full index, and the manifest, and maps the indexes and string tables in place (mmap, read-only) rather than reading them. Each record find() returns is checked as it is returned; each run must lie in a data region of its own commit or an earlier one, which the reader learns by walking every commit's record once, on first need. The whole state (every index's order, every record, the live count, collisions, features) is checked the first time something needs all of it: entries(), the content digest, check() (§12). On a cartridge of 100,000 entries: open 8 ms, a find 9 µs, the whole state 107 ms.

find() returns the entry, or Code::not_found, or the error that stops it; entries() returns the live entries, or the error that stops them.

The tests

tests/testing.cppm (sq.cart.testing) writes 3.0 cartridges byte by byte for the tests, including the broken ones a writer must never write, with real zstd frames and a trained dictionary (tests/zstd_fixtures.inc). test_redteam.cpp has one case for each finding of the red-team review that a reader can see.
