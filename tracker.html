Sprint tracker

Tasks are pull requests; a merge closes one. Read live from GitHub.

Every task is a pull request. A branch is pushed and GitHub Actions builds and checks it; while a check is red the task is blocked, once it is green it is ready, and a merge makes it done. A sprint is the milestone a pull request is filed under or, for one with none, the week (Monday to Sunday) it was opened or merged. Work that is planned and has no pull request yet waits under To do, whatever the sprint.
