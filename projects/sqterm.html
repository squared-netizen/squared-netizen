Repositorysquared-netizen/sqterm

sqterm is a terminal emulator for Android written as a squared application: a shell in a pseudo-terminal, drawn by squared, with no Java of its own. It is inspired by Termux and is side-loaded rather than published on Google Play.[1]

Overview

The shell runs in a pseudo-terminal on the model's thread, its output parsed by squared's terminal core and published as a snapshot; the TerminalView draws the newest screen from one glyph texture on the UI thread.[1] Its programs come from its own prefix, files/usr, filled from packages: a few carried in the APK and unpacked at first start, and larger ones installed with pkg from a file.[2] GitHub Actions builds every package for Android API 28 and publishes it to a release; the phone fetches them as a deliberate step, and every build stays offline.[2]

Concept

Packages are built on CI, fetched on purpose, and installed into sqterm's own prefix.

Architecture

Application

A Shell model owns the pty and a sq::term terminal; a TerminalView widget draws it and sends keys back; Glyphs holds the fonts, mapped from the APK, and the glyph atlas for the whole process.[1]

Prefix and packages

Recipes in packages/ build each package; every archive carries a cartridge-style manifest listing its files, which pkg uses to list, upgrade, remove and back up packages. Each package has its own key, so a change rebuilds only it and what depends on it.[2]

Toolchain

clang and lld 23 as one binary, a sysroot built from AOSP's bionic rather than the NDK, and static libc++ 23 runtimes with the import std sources. clangd, clang-tidy and clang-doc come as a package of their own, so the compiler package stays small.[2]

Platform

Running in the background through squared's foreground service, with a notification and an optional wake lock.[1]

Features

  • A shell in a pty with scrollback, rotation and the keys of a hardware keyboard.[1]
  • Copy and paste the way Termux does it: word selection, handles, and bracketed paste.[1]
  • Keeps running in the background, with a notification; survives a swipe from the recent apps.[1]
  • Pinch to scale the font, kept across launches.[1]
  • Its own prefix with zsh, bash, coreutils, sed, grep, gawk and make.[2]
  • pkg: list, install from a file (optionally deleting it), remove, back up.[2]
  • C, C++ and C++23 import std compiled and run on the phone, from the prefix.[2]
  • The tools around the compiler: clang-format, clang-scan-deps (module dependencies), clangd, clang-tidy and clang-doc.[2]

Use cases

  • A shell on the phone that keeps working with the screen off.
  • Building and running C and C++ programs on the device, offline.
  • Long-running jobs (a build, a download) that outlive the app's window.
