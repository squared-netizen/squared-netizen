squared-examples holds independent, complete applications built with the squared framework and the squared-pg generator, kept outside both repositories so that experiments cannot change their release code.[1]

Overview

The README describes the collection as empty while squared-pg is rewritten; the repository itself holds two generated Android applications, demo and hello, each a full workspace with its own copy of the framework at a recorded revision (SQUARED_REV).[1][2] Each builds an APK with make on a phone, with no Gradle, no Android Studio and no Java in the build.[2]

Concept

Each example is a generated workspace that builds on its own.

Architecture

Workspaces

Each application is a complete workspace: sq_app/ (the application), sq_android/ (the platform layer), squared/ (the vendored framework), mk/ and tools/.[2]

Repository model

Applications stay outside the framework and generator repositories, so neither can change them by accident.[1]

Features

  • Two Android applications, demo and hello, generated from the Android template.[2]
  • Build, package, install and run from Termux: make, make apk, make install, make run.[2]
  • A development Console reachable from Termux, with no adb.[2]

Use cases

  • A known-good app to try squared on a phone.
  • A reference for what squared-pg generates.
